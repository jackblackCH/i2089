## Differences to the reference

1. **Look:** two looks in the switcher ("Blog" row). *Clone* = system font, white page, like the reference. *Site* = the same layout in Helvetica Neue LT Pro Extended on the dark site palette. Extended is about 25 % wider, so a 704px line holds ~65 characters instead of ~85, and titles wrap earlier.
2. **Header:** the reference shows only the blog name. Ours shows "Marc Illien / Blog" and the site nav (PFD R5: the offers stay one step away). On phones the nav wraps to a second line, so the title starts 49px lower.
3. **Byline:** one author and the date; the reference has co-author lines. Light italic (weight 200) exists only in the system font; the site look uses 400.
4. **End of a post:** our contact ("Let's talk. Zürich or remote." and the email button) and a colophon. The reference ends with footnotes, citations and an appendix; those are not cloned.
5. **Not cloned:** footnotes, bibliography, table of contents, wide figures beyond the text column, interactive figures.
6. **Date format:** Swiss German, "12.11.2026" (changed on request; the reference writes "December 19, 2025").
7. **Frame:** blog pages leave the two-column frame. In the clone look the jump from the dark site to a white page is strong.
8. **Not in the nav yet:** the only post is a draft (visible on localhost and previews only), so /blog is not linked from the main nav until a real post exists.

## How posts work

Markdown files in `content/blog/`, front matter `title`, `date` (YYYY-MM-DD), `description`, optional `tldr`, `draft: true|false`. An image alone in a paragraph becomes a figure; its Markdown title becomes the caption. Drafts never reach production, the sitemap or llms.txt.
