# Design variants under test (2026-11-12)

Two requests from review, built as switchable variants on the `pfd-fixes` branch. The switcher sits in the bottom bar ("Variants", key `v`, replay key `r`) on localhost and Vercel previews only. Production gets the defaults in `app/_shared/variants.ts`.

| Axis | Options | Default |
|---|---|---|
| Motion (i2089 → MARC ILLIEN) | Split-flap, Decode, Wipe, Blur | Blur |
| Timing | Once, rest on name · Hover / focus · Once, back to i2089 · Slow loop | Slow loop |
| Fit | Two lines (0.942 of the logo size, same width as i2089) · One line scaled (0.4505) · One line, same size (logo shrinks to 0.4505, i2089 centred in the MARC ILLIEN box) | One line, same size |
| Labels | Selected look + filled button · Selected look + outlined button · Service terms only · Off | Selected + filled |

**Defaults chosen by Marc (2026-11-12):** Blur, Slow loop, One line same size. Slow loop goes against R1; it is his call, recorded here. The switcher has "Reset to defaults" for browsers that stored an older choice.

**Footer (2026-11-12):** the four nav links sit in four equal columns across the wordmark column, each centred (equal gaps edge to edge on phones, where equal cells are too narrow). The copyright shows only on mobile now; on md+ the foot row belongs to the nav.

## PFD notes per option

- **Once, rest on name** meets R1 (nothing moves while people read) and R2 (the name is readable at rest). It also brings the name back on mobile subpages, where the byline had to go.
- **Hover / focus** and **Once, back to i2089** rest on i2089. The separate name line under the logo was removed on request (2026-11-12), so with these two the name is not visible at rest: R2 fails for them.
- **Slow loop** goes against R1 (the typewriter was removed for that reason). It is in the switcher only because it was asked for.
- **Selected labels + filled button**: both are light filled boxes, so the button competes with the labels (R5, Green & Swets 1966). **Outlined button** keeps a clean split: filled means label, outlined means action. **Service terms only** is the least risky.
- All motions sweep left to right by each letter's x position, use the font's own glyphs, and turn into a 150 ms cross-fade under reduced motion.

When one option per axis is chosen, fold it in and delete the rest (`variants.ts`, `logo-mark.tsx`, the variant CSS in `shared.css`, `app/_compare/variant-panel.tsx`).
